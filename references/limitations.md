# Limitations, maturity and deployment boundaries

This is a research-workflow release, not a production-certified autonomous investment system. Targeted source review covers operationally relevant sections, with a chapter map for the full curriculum. It is not a replacement for reading the source or for current scientific, financial, legal and methodological diligence.

The engine validates structure, references, dates, selected consistency rules and handoffs. It cannot establish whether a cited source entails a claim, whether an issuer estimate is true, whether a scenario is coherent, whether reviewers are independent, or whether a strategy predicts returns. Agent text must still be reviewed by qualified analysts. Fixed synthetic confidence values are demonstration placeholders only.

No live data tools or LLM adapter are installed in this package. A host agent must provide permitted retrieval and reasoning. Feed licensing, authentication, API budgets, source availability and vendor methodologies require separate integration. No background tasks, monitoring alerts, trades, votes or external messages run automatically.

Inputs and outputs can contain confidential information: keep run directories outside source control and enforce filesystem access. Local digest/revision controls are not an authentication, encryption, adversarial tamper-resistance or regulated retention solution. Human approval is an explicit caller attestation, not proof of identity. Do not treat a model's use of the review command as legitimate approval.

Current standards, laws, scientific datasets, bond terms and market values need verification in the user's research environment. Historical textbook assertions are not current legal conclusions. The generic calculation helpers have tightly stated scope; sovereign, callable, convertible and securitised instrument pricing requires the appropriate specialist model.

The source PDF remains outside the repository. Only original operational paraphrases, locators and synthetic examples are included. Before public distribution, the owner should review rights, select a licence and inspect the package for confidential additions.
