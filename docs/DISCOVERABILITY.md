## Implemented in the repository

The README begins with a direct project definition and intended audience. Descriptive headings, answer-first [FAQs](FAQ.md), internal links, a [claim register](claims.json), [software citation metadata](../CITATION.cff) and an optional [LLM reading index](../llms.txt) make the evidence and limitations easy to locate. No hidden keywords, fabricated credentials, reviews, testimonials, citations or ranking instructions are included.

Google's [AI-features guidance](https://developers.google.com/search/docs/appearance/ai-features) explains that normal SEO practices apply to its AI search features; no special AI file or schema is required. Clear textual content and internal navigation are appropriate, but indexing and inclusion are not guaranteed. GitHub's [citation documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files) explains software citation metadata, not a search-ranking credential. Guidance reviewed 2026-09-23.

The optional `llms.txt` is just a compact reading index. It neither changes GitHub's crawler settings nor guarantees adoption by AI search systems. Repository source files do not control the canonical tag, HTTP metadata, robots policy or JSON-LD rendering of GitHub's repository page. No standalone site or search-index submission is deployed here.
